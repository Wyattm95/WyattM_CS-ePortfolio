Artifact Overview

This artifact is a rescue animal management application developed in Java. The application is console-based and allows users to intake new rescue dogs and monkeys, reserve animals, and print lists of dogs, monkeys, or available rescue animals through a menu system. This project was originally developed as a final project while I was enrolled in IT-145: Foundation in Application Development.
