Self Assessment

While enrolled in the Computer Science program, I have progressed from learning individual programming concepts to understanding how complete software systems are planned, developed, tested, secured, and maintained. Early coursework helped me build a foundation in programming languages, object-oriented design, and problem-solving. As I progressed through the program, projects became more complex and required me to consider how software components communicate, how data should be organized, how changing requirements affect development, and how testing and security contribute to software quality. Developing my ePortfolio gave me the opportunity to reflect on my previous work, apply what I learned throughout the program, and present the growth of my skills in a clear and organized way.

CS-250: Software Development Lifecycle gave me a stronger understanding of how collaboration and communication contribute to the success of a software project. Through coursework and projects based on Agile and Scrum practices, I examined how Product Owners, Scrum Masters, developers, and testers contribute different responsibilities and perspectives throughout the development process. I learned how user stories and acceptance criteria help translate stakeholder and end-user needs into clear development tasks. The course also showed me how clear and professional communication among developers, Product Owners, and testers supports shared understanding, accurate implementation, and better decisions throughout the development process. Sprint planning, reviews, and changing priorities also demonstrated how Agile teams can adapt when stakeholder needs or project requirements change. Overall, the course improved my understanding of how team members share information, coordinate responsibilities, and contribute to decisions throughout the software development lifecycle.

CS-300: Data Structures and Algorithms strengthened my ability to evaluate computing problems and choose solutions based on the needs of an application. While working on course projects, I compared vectors, hash tables, and binary search trees and considered how each structure affected storage, searching, and ordered output. This helped me understand that the most appropriate data structure is not always the one that performs a single operation the fastest. Instead, the decision should consider how the application will use its data, the trade-offs between different operations, and the overall requirements of the system. Using Big-O notation also gave me a clearer way to compare the efficiency of different approaches and explain why one solution may be better suited to a particular problem. This experience improved my ability to evaluate design trade-offs and make informed decisions when selecting data structures and algorithms.

CS-465: Full Stack Development brought together many of the software engineering, database, and security concepts I developed throughout the program. AS part of the course project, I built and connected an Express application, an Angular single-page application, a RESTful API, and a MongoDB database. Seeing these separate technologies function as one complete website gave me a more practical understanding of how the concepts I had studied could be applied in a real software system. I learned that full-stack development requires more than making each component work independently. The front end, server, API, and database must be designed to communicate reliably, and changes to one part of the application can affect the rest of the system. The project also strengthened my understanding of how application data is created, retrieved, updated, and verified as it moves between an API and a database. In addition, I gained experience with practices that support application security, including protecting API access, controlling who could modify data, validating information passed between components, and preventing sensitive or unnecessary files from being included in version control. This course showed me how software design, database management, testing, and security work together to create an application that is functional, maintainable, and useful to its intended users.

Throughout the Computer Science program, I developed a broader understanding of the communication, organization, adaptability, testing, and responsible decision-making involved in professional software development. I learned that professional computing involves more than writing functional code. It requires collaborating with others, understanding stakeholder and user needs, and clearly explaining technical decisions to different audiences. It also requires evaluating algorithms and data structures based on the needs of a problem, designing software and databases that can be maintained as requirements change, and considering security throughout the development process. Across the program, I developed a stronger understanding of how these areas support one another and contribute to software that is reliable, efficient, secure, and useful to its intended users. These experiences have prepared me to approach future projects with greater professionalism, stronger communication skills, and a better understanding of what is expected in a professional work environment.

The artifacts included in my ePortfolio highlight different areas of my growth throughout the Computer Science program. The Inventory Tracker enhancement demonstrates improvements to software design and engineering through the redesign of an existing C++ application as a modular Java application. These changes improved class organization, maintainability, file handling, and reusable inventory-data management. The Rescue Animal enhancement demonstrates how selecting a more appropriate data structure can improve application efficiency and organization by replacing repeated ArrayList searches with HashMap-based record storage while also strengthening validation and record management. The database enhancement builds on the Rescue Animal application by integrating MongoDB, improving data persistence by allowing records to be saved, loaded, and updated across program sessions.

Together, these artifacts demonstrate my ability to evaluate existing software, identify areas for improvement, and apply concepts from across the Computer Science program. Each enhancement focuses on a different part of professional software development, including modular design, data-structure selection, validation, database integration, and controlled data access. The portfolio also shows my ability to plan technical improvements, implement changes, test functionality, and explain how my work supports broader computing requirements.

Code Review

Category One: Software Engineering and Design

In this category, I redesigned an existing C++ Inventory Tracker as a more modular Java application. The enhanced version seperates file handling, menu navigation, and inventory operations into focused classes, improving the organization, maintainability, and flexibility of the program. I also replaced repeated file searches with resuable inventory data stored in a HashMap.

Inventory Tracker

Category Two: Algorithms and Data Structures

In this category, I enhanced a Java Rescue Animal application by replacing separate ArrayLists and repeated linear searches with HashMap-based record storage. I also improved input validation, selected more appropriate data types, strengthened encapsulation, and reorganized the application into focusd classes. These changes improved record lookup efficiency, data quality, and the overall structure of the application.

Rescue Animal

Category Three: Databases

In this category, I expanded the Rescue Animal application by connecting it to a MongoDB database. The enhancement allows animal records to be saved, loaded, and updated across multiple program sessions instead of existing only in memory. Database operations were placed in a dedicated class, while the application continued using HashMaps for runtime operations.
